Secure Payment

Secure Payment Gateway Integration

Security should not depend on every user remembering every protective step. This graduation project integrates protection directly into the payment flow through authentication, password hashing, encrypted communication, rate limiting, and webhook verification, allowing security to work in the background and fit into existing systems.

Node.js • Express • PostgreSQL • PayPal • JWT
Educational Platform

"Tifl" Educational Platform

During my cooperative training with Social Development, I noticed that the children's library lacked a digital component to extend learning beyond its shelves. I independently turned that gap into Tifl: a large, integrated Arabic platform with 32 interactive games across four sections, secure sign-in, a parent dashboard, child profiles, and play-time tracking.

HTML • CSS • JavaScript • PHP • MySQL
